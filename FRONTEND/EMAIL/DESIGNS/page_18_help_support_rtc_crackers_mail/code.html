When composing a quote or lorry receipt (LR) dispatch from the template picker, use double curly brace syntax. The system automatically reconciles variables with the local PostgreSQL sales records:

{{customer_name}} → Client legal trade name
{{order_number}} → RTC-2024-XXXX token
{{order_total}} → GST-inclusive Rupee sum

If any variable is missing from the record, the compose drawer alerts you with an amber pill before outbound transmission.
