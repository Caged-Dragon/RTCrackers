Bulk Product Import — Excel / CSV

Use the existing connected product database. Upload an .xlsx, .xls, or .csv file. The first row must contain column names. The importer checks whether the first column is only a serial-number column and ignores it automatically when detected.

Recommended columns: name, category, size, price, mrp, stock_quantity, image, description, specifications, safety_information, featured, bestseller, new_arrival, festival_box_eligible, keywords. Only name, category, and price are required.

No products in Postgres database yet? Use supabase/seed.sql to import the full 160-product starter catalog in one click.

Delivery PIN Codes

Add the Tamil Nadu PIN/post-office areas where RTCrackers accepts delivery. Customers can check these PIN codes on the ordering page.

The customer lookup checks this database first. If a pincode is missing, the server can verify its postal details against Government of India open postal data and send the first order for that pincode to administrator approval.

Upload a spreadsheet with headers such as pincode, post_office, district, state, estimated_delivery_days, delivery_available. A serial-number/S.No first column is automatically ignored. No serial number is stored as a pincode.
